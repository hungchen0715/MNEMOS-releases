# MNEMOS downloads

Install MNEMOS once from here. After that it updates itself.

| | First install | Updates |
|---|---|---|
| **Windows** | Download [MNEMOS-Windows-Setup.exe](https://github.com/hungchen0715/MNEMOS-releases/releases/latest/download/MNEMOS-Windows-Setup.exe) and run it. If SmartScreen appears: **More info → Run anyway**. | Automatic. MNEMOS installs the new version and restarts (never while recording). |
| **Mac** | Download [MNEMOS-mac.zip](https://github.com/hungchen0715/MNEMOS-releases/releases/latest/download/MNEMOS-mac.zip), unzip, move **MNEMOS** to **Applications**. The first time: right-click → **Open** → **Open**. | Automatic, the same way. Or **MNEMOS → Check for Updates…** |
| **iPhone** | In **SideStore → Sources → +**, add `https://github.com/hungchen0715/MNEMOS-releases/releases/latest/download/sidestore.json`, then install **MNEMOS** from it. | SideStore shows **Update**; MNEMOS also shows a banner. One tap. |

Then open MNEMOS → Settings and enter the server address and key you were given.
